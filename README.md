# はんぶんこ

ふたりの生活費を記録して、月初に「どちらがどちらにいくら渡せば折半になるか」をまとめて計算する Web アプリです。

## できること

- **支出の記録**: 金額・内容・カテゴリ・日付・払った人・メモ・レシート写真
- **負担の分け方**: 基本は半々。支出ごとに「全額どちらか」「割合（%）」「金額」に変更可能
- **固定費**: 家賃・ネット代などを登録しておくと、毎月はじめにアプリを開いたとき自動で記録
- **精算**: 月ごとに「A → B ○○円」を自動計算。10円単位で、立て替えた側（受け取る側）が得をするよう切り上げ
- **月初ポップアップ**: 前月が未精算なら精算額を表示し、そのまま「精算済み」にできる
- **精算済みの月はロック**: 誤って編集しないよう変更不可（設定の精算履歴から取り消し可能）
- **集計**: 月のカテゴリ別内訳、6か月の推移
- **レシート自動読み取り（任意）**: 写真を撮ると Claude が金額と内訳を読み取り、カテゴリが複数あれば分けて登録
- **途中の送金**: 「送金」カテゴリで、払った人＝渡した人、負担＝全額（受け取った人）で記録すると精算額から差し引かれる
- 数字 PIN でログイン（5回間違えると5分ロック）、スマホのホーム画面に追加して使える

## 構成（すべて無料枠で運用可能）

| 役割 | サービス |
|---|---|
| アプリ本体 | Next.js 16（Vercel の Hobby プラン） |
| データベース・画像保存 | Supabase（Free プラン） |
| レシート読み取り | Anthropic API（任意・従量課金。1枚あたり数円程度） |

> Supabase の Free プランは、1週間まったくアクセスがないとプロジェクトが一時停止します。ふたりで毎日使っていれば問題ありませんが、停止した場合は Supabase の管理画面から再開できます（データは消えません）。

## セットアップ

### 1. Supabase

1. https://supabase.com でプロジェクトを作成（リージョンは Tokyo がおすすめ）
2. 左メニュー「SQL Editor」で `supabase/migrations/0001_init.sql` の中身を貼り付けて実行
3. 「Project Settings → API」から次の2つを控える
   - Project URL → `SUPABASE_URL`
   - `service_role` の secret キー → `SUPABASE_SERVICE_ROLE_KEY`（**絶対に公開しないでください**）

### 2. Vercel

1. https://vercel.com でこのリポジトリをインポート
2. 「Environment Variables」に `.env.example` の項目を設定

| 変数 | 内容 |
|---|---|
| `MEMBER1_NAME` / `MEMBER2_NAME` | ふたりの表示名 |
| `MEMBER1_PIN` / `MEMBER2_PIN` | ログイン用の数字（4〜12桁、6桁以上推奨） |
| `SESSION_SECRET` | ランダムな長い文字列（`openssl rand -base64 32` など） |
| `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` | 上で控えた値 |
| `ANTHROPIC_API_KEY` | レシート自動読み取りを使う場合のみ（https://console.anthropic.com で発行） |

3. デプロイして、表示された URL をふたりのスマホで開き、「ホーム画面に追加」

> メンバー1・2の順番を後から入れ替えると、過去の「払った人」も入れ替わって見えるので注意してください。名前や PIN の変更は自由です。

## 開発

```bash
npm install
cp .env.example .env.local   # MEMBER*_PIN だけ入れれば動きます
npm run dev
```

`SUPABASE_URL` を設定しない場合、データは `.data/` 以下のローカルファイルに保存されます（開発用）。

```bash
npm test        # 精算計算などのユニットテスト
npm run lint
```

## 計算方法

支出ごとに「各自の負担額」を出し（半々なら金額の1/2）、月の合計で

- 払った額 − 負担額 がプラスの人 = 受け取る人
- その差額を10円単位に切り上げたもの = 精算額

例: 家賃120,000円・ネット5,000円・日用品10,000円を彼女、食費40,000円を彼氏が払った月 → 合計175,000円、ひとり87,500円 → 彼氏が彼女に **47,500円**。

端数を「払う側が得」にしたい場合は `src/lib/settlement.ts` の `ROUNDING_FAVORS` を `"payer"` に変更してください。
